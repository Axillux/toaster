Toaster Docs

Getting started

  1. Add Toaster to your server.
  2. Give its role the permissions you want it to use (see below).
  3. Run /settings and pick a punishment and a log channel.

How it works

Toaster reads every message in the servers it is in. Text and images are turned into vectors and compared against a scam database. On a match:

  1. The scam message is deleted immediately.
  2. The scammer gets a DM explaining why.
  3. The punishment from your /settings is applied.
  4. A sweep removes every other message the account sent, in all channels and threads, and repeats until a pass finds nothing left.

A meme database overrides scam matches on known-good images, so regular memes are not punished. One detection also punishes the account in every other server Toaster is in, using each server's own settings.

Commands

  • /scan days:1-90 — clean up old scam. Options: dry_run:True (report only, delete nothing), channel (scan one channel only). Without dry_run it deletes found scam and punishes the senders.
  • /settings — punishment, mute duration, log channel, DM template.
  • /report — detections, deletions and punishments for this server, or globally with scope:global.
  • /about — what the bot is, server and user counts.
  • /avatar [user] — full-size avatar.
  • /legal — Privacy Policy and Terms of Service links.
  • /ping — latency.

/settings

  • Scam Punishment — mute, kick (default) or ban.
  • Scam Mute Duration — 1 to 28 days, used when the punishment is mute.
  • Log Channel — where scam alerts, scan progress and results are posted.
  • DM Template — the DM text sent to the scammer. Placeholders: {action}, {server}, {days}.

/scan

Walks channel history back up to 90 days and applies the same detection as live moderation. Progress is posted live to the log channel, including a direct link to every scam message the moment it is found. When it finishes, the same message becomes the summary: how many messages were checked, what was found, deleted, and whether anything failed. Detected scam variants are sent to the bot owner for review.

Run it with dry_run:True first to preview what would be deleted, then without it to actually clean up. Discord rate limits are handled automatically, so large scans simply take longer.

What the bot needs

  • Delete messages: Manage Messages, View Channel, Read Message History.
  • Kick: Kick Members.
  • Ban: Ban Members.
  • Mute: Moderate Members (Timeout Members).
  • The bot's role must be above the members it should punish. Server owners cannot be punished.
  • For the log channel: View Channel and Send Messages there.

Review cards

Every detected scam is also sent to the owner as a card with the image and buttons: add to the scam database, add to the meme database, or ignore. New variants approved this way improve detection for everyone. Server admins see every incident in their log channel.

Notes

  • The bot never pings anyone. All mentions are rendered as plain text.
  • DMs are sent only to users who were punished.
  • Detection can make mistakes. Check the log channel and adjust the database through review cards.
  • DMs (direct messages) are not moderated.
